# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful and harassment-free
environment for everyone participating in MAISON.

## Expected Behavior

Participants are expected to:

- Be respectful.
- Communicate constructively.
- Accept reasonable criticism.
- Focus on technical issues rather than individuals.
- Respect different perspectives and experiences.
- Help maintain a welcoming community.

## Unacceptable Behavior

The following is not acceptable:

- Harassment
- Discrimination
- Personal attacks
- Trolling
- Threats
- Deliberate intimidation
- Publishing private information without permission
- Sexualized harassment
- Spam or disruptive behavior

## Enforcement

Project maintainers may remove, edit or reject comments, issues and pull
requests that violate this code of conduct.

Serious or repeated violations may result in temporary or permanent exclusion
from the project.

## Reporting

If you experience or observe unacceptable behavior, contact the maintainer
through the project's private communication channels.

Please do not use public GitHub issues for sensitive reports.
